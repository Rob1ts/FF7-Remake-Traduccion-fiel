# Condiciones de uso

## Traducción

La traducción se ofrece **gratuitamente y para uso personal**. Puedes:

- Usarla con tu copia legal del juego.
- Compartir el enlace a este repositorio o a sus releases.
- Modificarla para uso propio.

No puedes:

- Venderla ni incluirla en productos de pago.
- Presentarla como traducción oficial.
- Redistribuir el texto japonés original del juego: no forma parte de este repositorio.

## Código

Los scripts de este repositorio (`herramientas/`) se publican bajo la licencia **MIT**. Puedes reutilizarlos, modificarlos y redistribuirlos citando la procedencia.
